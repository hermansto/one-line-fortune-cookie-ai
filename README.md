## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fortune-cookie-ai-out node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and reads it back to verify it matches exactly.
